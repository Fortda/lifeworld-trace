# OmniPlayer 实验

独立视觉原型，未接入正式 UI。

## notes_timeline_chars（笔记字迹时间轴）

按「字入框时间戳」把字心贴在横轴上；缩放/刻度对齐仪表盘；重叠时上下换行并竖直居中。

可选素材：同目录放 `notes_timeline_sample.json`（从本机笔记 `user_glyphs` 导出，不进 Git）。没有该文件时仍可在输入框里试打。

**打开：** 在 `omniplayer/` 执行 `npm run dev`，浏览器访问  
http://127.0.0.1:1420/experiments/notes_timeline_chars.html
